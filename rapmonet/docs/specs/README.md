# Spécifications

Déposer ici les spécifications reçues, une par sujet, par exemple :

- `lis-gim.md` / `.pdf` : format du fichier LIS (TC, TCR, attributs)
- `vss-visa.md` : format des fichiers EP* du dossier VSS
- `ejournal-ncr.md` : structure des journaux électroniques NCR
- `amplitude-bkhis.md` : colonnes de l'extraction BKHIS
- `rapprochement-*.md` : règles de rapprochement
